## What is an Operating Engineer?

<img src="https://mindx.edu.vn/logo.svg" alt="MindX Logo" class="mindx-logo" />

**Operating Engineer** - Mindset focused on:

- **Operations-first, non-invasive** - Maintain systems without code changes
- **Automation-driven** - Automate repetitive tasks for efficiency
- **User-focused** - Quick resolution via workarounds/automation
- **Boundary-aware** - Know when to escalate to dev team

---

## Key Responsibilities & Principles

<img src="https://mindx.edu.vn/logo.svg" alt="MindX Logo" class="mindx-logo" />

**Responsibilities:**
- System operations & monitoring
- Ticket handling & customer support
- Automation & optimization
- Incident response via workarounds
- Documentation & knowledge sharing

**Core Principles:**
- **Non-invasive:** Solve through automation/workarounds, NO code core intervention
- **Automation-first:** Automate repetitive tasks over manual work
- **Speed:** Provide solutions quickly, no need to wait for code fix
- **Boundary awareness:** Know when to escalate to dev team

## Ticket Handling: Traditional Approach

<img src="https://mindx.edu.vn/logo.svg" alt="MindX Logo" class="mindx-logo" />

**Software Engineer mindset:**

- May assume user error
- Focus on code changes to fix
- May delay response (wait for code fix)
- Limited production context (work in dev environment)

---

## Ticket Handling: Operating Engineer Approach

<img src="https://mindx.edu.vn/logo.svg" alt="MindX Logo" class="mindx-logo" />

**7-Step Process (Non-Invasive):**

1. **Reception** - Log ticket (< 15 min)
2. **Initial Response** - Acknowledge (< 30 min)
3. **Diagnosis** - Investigate via monitoring/logs (NO code changes)
4. **Resolution** - Automation/Workaround/Config (NO code core intervention)
5. **Communication** - Update every 24h
6. **Follow-up** - Confirm resolution
7. **Automation** - Document patterns to automate next time

---

## Ticket Classification

<img src="https://mindx.edu.vn/logo.svg" alt="MindX Logo" class="mindx-logo" />

**Impact-based prioritization:**

- **Standard:** < 5 users - Normal priority
- **Priority:** 5-25 users - Expedited handling
- **Expedite:** > 25 users - Emergency response
- **Fixed Deadline:** Time-driven

**Key:** Classify by **impact**, not just order received

---

## Example: Login Issue Ticket

<img src="https://mindx.edu.vn/logo.svg" alt="MindX Logo" class="mindx-logo" />

**Operating Engineer workflow (Non-Invasive):**

- **Triage:** Classify by impact (Standard/Priority/Expedite)
- **Investigate:** Check production metrics and logs first
- **Diagnose:** Check account status, system health (via monitoring)
- **Resolve:** 
  - Account issue → Reactivate/reset password (operations)
  - System issue → Workaround or escalate to dev team
  - Create automation script if pattern repeats
- **Follow-up:** Confirm and document pattern to automate
